Elevor360D CV & Resume Builder Pro V5.2 — Universal Advertising Manager V1 compatible

Upload all files and folders to the existing CV Builder GitHub Pages repository.
The app reads advertising/adverts.json (the exact feed exported by Universal Advertising Manager V1).
Upload the manager's exported adverts.json into advertising/ and its downloaded images into advertising/images/.
In Universal Advertising Manager, choose Destination category = Business / utility apps or All participating apps.
For a specific app, use app ID: cv-resume-builder-pro.
The image paths in the manager feed are already in images/filename.jpg format.
The default example advert is included for testing.
The old root-level adverts.json is no longer used.
The CVs and cover letters remain saved on the same browser and URL. Back up before upgrading.
Do NOT publish the manager itself to the public app repository.
