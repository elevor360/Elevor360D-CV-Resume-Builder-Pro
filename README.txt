Elevor360D CV & Resume Builder Pro V5.1 — Advertising folder fix

Upload ALL files and the advertising folder to the same GitHub Pages repository.

The example picture is in advertising/elevor360d-advert.jpg.
To change it, upload a JPG or PNG into advertising/ and enter its path in adverts.json, e.g. advertising/my-business.jpg.
Set enabled true to display it. Add more objects to the adverts array for rotation.
The advert image does not appear on printed CVs or cover letters.
Keep the same GitHub Pages URL to retain locally saved CVs. Back up CVs and cover letters first.
